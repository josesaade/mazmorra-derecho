# Mazmorra del Derecho 🎮

Juego educativo interactivo sobre Derecho Intelectual para estudiantes de la Universidad de la Costa.

## Descripción

Un juego tipo RPG donde los estudiantes forman grupos y enfrentan desafíos educativos para reunir las 4 Gemas del Conocimiento y derrotar al Dragón del Acabarropismo.

## Instalación

```bash
npm install
```

## Ejecución

```bash
npm run dev
```

Abre tu navegador en `http://localhost:5173/`

## Build

```bash
npm run build
```
